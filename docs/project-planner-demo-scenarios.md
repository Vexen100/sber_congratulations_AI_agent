# Project Planner Demo Scenarios

Сценарии предназначены для ручной проверки `/project-planner` в mock/offline режиме.
Они не требуют GigaChat credentials и не используют сеть.

> Эти сценарии предназначены только для ручной проверки прототипа.  
> Бюджеты, сроки и ожидаемые предупреждения являются тестовыми и не считаются экспертной оценкой.

## 1. HR-ивент: фестиваль талантов

Input:

- Суть идеи: `Провести фестиваль талантов в Уральском банке с региональным охватом и финальной защитой лучших команд.`
- Дедлайн: через 90 дней.
- Бюджет: `1500000`
- География: `Свердловская область`
- Стейкхолдеры: `HR, руководители направлений, сотрудники банка`
- Текущие ресурсы: `Команда внутренних коммуникаций и площадки банка`
- Технологические ограничения: `Использовать только согласованные внутренние каналы`
- Акценты: `Учесть 185-летие Сбера и идеи фестиваля 2023 года`

Ожидаемо:

- Предварительная бюджетная оценка по тестовым справочникам.
- Roadmap с фазами, RACI, 3 концепции и рекомендуемой концепцией.
- DOCX скачивается и содержит сценарий защиты.

## 2. IT-внедрение внутреннего сервиса

Input:

- Суть идеи: `Внедрить внутренний сервис регистрации инициатив сотрудников с маршрутизацией на руководителей направлений.`
- Дедлайн: через 120 дней.
- Бюджет: `2500000`
- География: `Челябинская область`
- Стейкхолдеры: `IT, HR, руководители подразделений, служба информационной безопасности`
- Текущие ресурсы: `Внутренняя IT-команда и корпоративный портал`
- Технологические ограничения: `Не использовать внешние SaaS, интеграции только через внутренний контур`
- Акценты: `Сделать пилот на одном направлении и подготовить масштабирование`

Ожидаемо:

- Концепции различаются по управляемости, вовлечению и пилотированию.
- В рисках появляются согласования и IT/методическая поддержка.
- В DOCX есть RACI и таблица команды.

## 3. Маркетинговая кампания

Input:

- Суть идеи: `Запустить региональную маркетинговую кампанию для повышения узнаваемости программ поддержки малого бизнеса.`
- Дедлайн: через 75 дней.
- Бюджет: `1800000`
- География: `Республика Башкортостан`
- Стейкхолдеры: `Маркетинг, продажи, партнёры, руководители офисов`
- Текущие ресурсы: `Маркетинговая команда, база партнёров, внутренние каналы коммуникации`
- Технологические ограничения: `Согласование макетов и текстов через бренд-команду`
- Акценты: `Сделать акцент на предпринимателей и локальные бизнес-сообщества`

Ожидаемо:

- В ресурсах есть маркетинг и коммуникации.
- В концепциях видны разные каналы охвата аудитории.
- Предупреждение о предварительности оценки бюджета сохраняется.

## 4. Обучающая программа

Input:

- Суть идеи: `Организовать обучающую программу для новых руководителей по проектному управлению и работе с командами.`
- Дедлайн: через 100 дней.
- Бюджет: `1200000`
- География: `Тюменская область`
- Стейкхолдеры: `HR, учебный центр, руководители направлений`
- Текущие ресурсы: `Внутренние эксперты, LMS, календарь очных встреч`
- Технологические ограничения: `Материалы должны быть доступны во внутренней LMS`
- Акценты: `Включить практическую защиту мини-проектов`

Ожидаемо:

- Roadmap отражает подготовку, запуск и защиту результата.
- Команда включает руководителя проекта, бизнес-заказчика, координатора и коммуникационную роль.
- DOCX содержит outline презентации.

## 5. Нереалистичный срок

Input:

- Суть идеи: `Подготовить и провести межрегиональный форум сотрудников с программой, регистрацией, коммуникациями и итоговой защитой.`
- Дедлайн: через 10 дней.
- Бюджет: `2000000`
- География: `ХМАО`
- Стейкхолдеры: `HR, руководители офисов, коммуникации`
- Текущие ресурсы: `Есть команда проекта, но нет подрядчиков`
- Технологические ограничения: `Только внутренние каналы согласования`
- Акценты: `Показать риски сжатого графика`

Ожидаемо:

- Warning о нереалистично коротком сроке.
- Roadmap строится как срочный план с параллельными работами.
- DOCX явно содержит warnings.

## 6. Нереалистичный бюджет

Input:

- Суть идеи: `Провести масштабную программу вовлечения сотрудников Уральского банка с региональными активностями и итоговым мероприятием.`
- Дедлайн: через 100 дней.
- Бюджет: `100000`
- География: `ЯНАО`
- Стейкхолдеры: `HR, коммуникации, региональные руководители`
- Текущие ресурсы: `Внутренняя команда и часть площадок`
- Технологические ограничения: `Без внешних рекламных платформ`
- Акценты: `Нужно показать бюджетные риски и варианты сокращения объёма`

Ожидаемо:

- Warning, что бюджет ниже предварительной оценки.
- Финансовые статьи рассчитаны с региональным коэффициентом.
- Концепции показывают разные уровни стоимости и трудоёмкости.

## 7. Неполные данные

Input:

- Суть идеи: `Сделать проект для сотрудников`
- Дедлайн: не указан.
- Бюджет: не указан.
- География: не указана.
- Стейкхолдеры: не указаны.
- Текущие ресурсы: не указаны.
- Технологические ограничения: не указаны.
- Акценты: не указаны.

Ожидаемо:

- Clarifications возвращают вопросы по идее, дедлайну, географии, стейкхолдерам и акцентам.
- При включённой генерации с допущениями отчёт создаётся в mock mode.
- Assumptions явно перечисляют недостающие исходные данные.
- При выключенной генерации с допущениями API возвращает понятную ошибку о нехватке исходных данных.
